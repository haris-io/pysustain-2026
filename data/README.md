# Scheme data

Add scheme records to `schemes.json` as a JSON array. Each record must contain
non-empty string values for `id` and `name`; `description` is optional and must
be a string when present. Additional fields may be included and are searchable
when they contain text or numeric values.

The checked-in dataset is intentionally empty. Verify eligibility and application
details with the official source for each scheme before acting on them.
